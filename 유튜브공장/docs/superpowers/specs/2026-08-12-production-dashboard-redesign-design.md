# 제작 대시보드 전면 개편 설계

## 목표

모바일과 Mac에서 영상 제작의 현재 상태, 대본, 영상 프롬프트, 수집 에셋, 편집 부족분, 검수 결과와 최종본을 한 화면 체계에서 확인하고 필요한 Human Gate만 승인한다.

## 정보 구조

대시보드의 상위 메뉴는 아래 일곱 개로 제한한다.

1. `현황`: 현재 실행 중인 작업, 진행률, 완료 단계, 다음 작업과 현재 유효한 승인 요청
2. `주제`: 후보 목록, 선택된 주제, 주제 승인과 수정 요청
3. `대본`: 내레이션 대본과 장면별 영상 프롬프트를 분리한 두 개의 보기
4. `에셋`: 수집·생성된 사진, 영상, 오디오를 미디어 중심으로 탐색하는 자료함
5. `편집`: 편집 진행 구간, 장면별 에셋 배치, 부족 에셋과 추가 생성 영상 요구
6. `검수`: 완성된 편집본 재생, 시간 구간별 문제, 통과 또는 편집 반송 승인
7. `최종`: 검수를 통과한 최종본 재생과 다운로드

`자료·출처`, `모델·도구` 같은 운영자용 메뉴는 상위 메뉴에서 제거한다. 출처와 권리 정보는 내부 기록에는 그대로 보존하되 에셋 기본 화면에는 표시하지 않는다.

## 현황 화면

- 가장 위에 현재 작업명, 상태, 경과시간과 간단한 설명을 표시한다.
- 전체 단계 진행률을 표시하되 모바일에서 읽을 수 있는 핵심 단계만 보여준다.
- 자동 작업이 실행 중이면 발견·수집·다운로드 수량을 갱신한다.
- 현재 유효한 Human Gate가 있을 때만 승인 카드를 표시한다.
- 승인 체크포인트보다 최신의 하위 산출물이 존재하면 그 승인은 오래된 것으로 판정하고 버튼과 카드를 숨긴다.
- 오래된 `proposal` 승인보다 최신 `media_collection`이 있으면 새 기획안이 만들어질 때까지 승인 요청 없음으로 표시한다.

## 대본 화면

대본 화면은 내부 탭 두 개로 구성한다.

- `대본`: 내레이션과 화면에 실제로 읽히는 문장만 장면 순서대로 표시한다.
- `영상 프롬프트`: 같은 장면 번호를 기준으로 화면 내용, 카메라, 움직임, 속도, 전환, 타이포, 실제 자료 사용, 생성 도구 전달 문구를 표시한다.

대본 또는 VisualPlan 산출물이 아직 없으면 현재 생성 단계와 준비 중이라는 설명을 표시한다. 임의 예시를 실제 산출물처럼 보여주지 않는다.

## 에셋 화면

- 상단에 전체·사진·영상·오디오 필터와 개수만 표시한다.
- 사진은 썸네일 그리드로 바로 보이고 누르면 전체 화면으로 확대한다.
- 영상은 대표 프레임을 썸네일로 보여주며 누르면 인라인 또는 전체 화면 재생한다.
- 기본 카드에는 에셋 종류와 파일명 또는 짧은 설명만 보여준다.
- 상세 출처, 라이선스, 원격 URL, 내부 파일 경로는 기본 UI와 모바일 API에서 노출하지 않는다.
- 브라우저는 인증된 프로젝트 미디어 라우트를 통해서만 로컬 에셋을 읽는다.
- 허용된 프로젝트 디렉터리 밖의 경로와 manifest에 등록되지 않은 파일은 제공하지 않는다.

## 편집 화면

- 장면별 상태를 `대기`, `에셋 준비`, `편집 중`, `완료`, `수정 필요`로 표시한다.
- 장면별로 배치된 에셋 수와 부족한 에셋 요구를 표시한다.
- 부족분은 `실제 자료 추가`, `생성 이미지 필요`, `생성 영상 필요`, `오디오 필요`로 구분한다.
- 실제 edit artifact가 없을 때는 빈 가짜 타임라인을 만들지 않고 준비 상태를 표시한다.

## 검수와 반송

- 검수 화면에는 가장 최신의 편집본 또는 검수본 플레이어를 표시한다.
- 검수 항목은 영상, 대본 일치, 음향, 자막, 사실, 영상미로 분리한다.
- finding은 시간 구간과 수정 지시를 함께 표시한다.
- 통과하지 못한 경우 시스템이 자동으로 편집 상태를 변경하지 않는다.
- 사용자가 `편집으로 되돌리기`를 승인하면 반송 결정을 기록하고 편집 단계가 다시 활성화된다.
- 검수 통과 역시 사용자 승인으로 기록한다.

## 최종 화면

- final review를 통과한 최종본만 재생과 다운로드를 허용한다.
- 통과 전에는 현재 막힌 단계와 준비 중 메시지만 표시한다.
- 공개나 외부 업로드는 별도 Human Gate이며 이 UI 개편 범위에 포함하지 않는다.

## 상태와 보안

- OpenMontage 프로젝트 디렉터리가 단일 source of truth다.
- 대시보드는 체크포인트와 artifact를 읽어 제한된 projection을 생성하며 외부 API를 호출하지 않는다.
- 승인 기록과 기존 산출물은 삭제하거나 덮어쓰지 않는다.
- 모든 변경 요청은 기존 CSRF, idempotency, optimistic concurrency 규칙을 유지한다.
- UI 새로고침과 미디어 조회는 상태를 변경하지 않는다.

## 완료 조건

- 모바일·Mac 모두 일곱 메뉴만 표시된다.
- 오래된 구성안 승인 카드가 보이지 않고 실행할 수도 없다.
- 수집된 사진과 영상이 에셋 화면에서 썸네일로 보이며 영상을 재생할 수 있다.
- 대본과 영상 프롬프트가 분리된다.
- 편집 부족분과 생성 영상 요구를 표시할 자리가 실제 artifact와 연결된다.
- 검수 실패 후 사용자 승인으로 편집에 반송할 수 있다.
- 통과한 최종본만 최종 화면에 표시된다.
